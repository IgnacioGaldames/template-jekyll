Este es un **template base para proyectos Jekyll**. Está configurado con las herramientas y patrones más comunes para comenzar un nuevo sitio de forma rápida.

## ¿Qué incluye?

- **Layouts** semánticos: `default`, `page`, `post`, `home`
- **Integración opcional** con Google Analytics 4, Google Tag Manager, Meta Pixel
- **Bootstrap 5** para componentes y grilla responsive
- **FontAwesome 6** para íconos
- **Navegación configurable** desde `_data/navigation.yml`
- **Schema.org** estructurado para SEO
- **Twitter/X Cards** y meta tags SEO automáticos via `jekyll-seo-tag`

## Cómo usar este template

1. Clona o usa este repositorio como template en GitHub
2. Edita `_config.yml` con los datos de tu proyecto
3. Configura la navegación en `_data/navigation.yml`
4. Agrega tus estilos en `assets/css/style.scss`
5. Crea contenido en `_posts/` y páginas `.md` adicionales

## Variables de configuración

| Variable | Descripción |
|---|---|
| `title` | Nombre del sitio |
| `url` | URL base del sitio (con https://) |
| `google_analytics_id` | ID de GA4 (G-XXXXXXXXXX) |
| `gtm_id` | ID de Google Tag Manager |
| `fb_pixel_id` | ID del Meta Pixel |
| `google_fonts` | Fuentes de Google (opcional) |
| `animate_css` | `true` para activar Animate.css |
